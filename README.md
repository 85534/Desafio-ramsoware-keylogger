# Simulação de Malware com Python

## Descrição

Projeto educacional desenvolvido em Python para estudar conceitos relacionados a ransomware e keylogger em ambiente controlado.

## Ransomware Simulado

O projeto cria um arquivo de teste dentro da pasta `testes`.

O script permite:

- criptografar o arquivo de teste;
- descriptografar o arquivo;
- gerar uma mensagem de resgate.

A chave de criptografia é criada para o laboratório.

## Keylogger Simulado

O projeto demonstra o conceito de registro de entradas em um arquivo `.txt`.

As entradas utilizadas no teste são fornecidas voluntariamente pelo usuário.

O objetivo é compreender o conceito de registro de teclas sem realizar captura furtiva de informações.

## Reflexão sobre Defesa

### Antivírus

Soluções antivírus podem ajudar na identificação e bloqueio de softwares maliciosos.

### Firewall

O firewall pode controlar conexões de rede e ajudar a bloquear comunicações não autorizadas.

### Sandboxing

Um ambiente isolado pode ser utilizado para analisar programas suspeitos sem expor o sistema principal.

### Backups

Manter backups é uma importante medida de proteção contra perda de arquivos causada por ransomware.

### Conscientização

Usuários devem ter cuidado com arquivos, links, programas e anexos de origem desconhecida.

## Objetivos de Aprendizagem

O projeto busca demonstrar:

- funcionamento conceitual de ransomware;
- funcionamento conceitual de keylogger;
- utilização de Python;
- importância da segurança da informação;
- medidas de prevenção e defesa.

## Ambiente

Projeto destinado exclusivamente a testes educacionais e controlados.
